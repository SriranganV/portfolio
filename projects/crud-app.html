01 · Overview

Problem Statement

Most business tools rely on persistent data. Implementing form validation, connection routing, transaction processing, and query returns requires solid understanding of underlying Java database APIs.

Project Purpose

The CRUD Web Application is a Java web tool built to practice full database-driven lifecycle flows. Instead of using high-level ORMs, it uses raw JDBC statements to interact with MySQL, helping me understand exactly how Java communicates with relational databases behind the scenes.

02 · My Contribution

Role & Contribution

  • Built complete server-side database workflows (Create, Read, Update, Delete queries).
  • Connected Java to MySQL using direct JDBC Connection, Statement, and PreparedStatement blocks.
  • Processed HTML form entries using HttpServletRequest and HttpServletResponse in Servlets.
  • Displayed relational table records inside dynamic JSP views using JSTL loops.
  • Managed session states and page-to-page servlet forwardings.
03 · Tech Stack

Technology

Java (JDK) Servlets API JSP & JSTL JDBC Driver MySQL / SQL Maven
04 · System Architecture

Data Flow Loop

Form Submit→ Servlet Controller→ JDBC Connection→ MySQL execution→ ResultSet Return→ JSP View / JSTL loop→ HTML Page Out
05 · Key Features

Core Capabilities

Create

Form submits capture inputs and trigger SQL INSERT prepared queries to create records.

Read

Triggers SQL SELECT queries, loops over ResultSets, and compiles object collections for views.

Update

Retrieves record details by primary ID, pre-fills HTML form inputs, and runs SQL UPDATE statements.

Delete

Allows users to remove specific entries safely via ID-mapped controller endpoints running DELETE operations.

09 · Results & Impact

Factual Outcomes

  • Successfully linked a Java backend runtime to persistent MySQL schemas without ORM abstractions.
  • Configured proper resource closing behaviors (try-with-resources) to prevent memory/connection leaks.
  • Provides solid foundational backing for discussing database connectivity in technical discussions.
10 · What I Learned

Key Takeaways

  • Direct JDBC drivers configurations and URL connection mappings.
  • Separation of dynamic data binding loops using JSTL tags (c:out, c:forEach).
  • Managing transactional scopes and committing changes inside database runtimes.
