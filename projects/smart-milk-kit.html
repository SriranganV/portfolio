01 · Overview

Problem Statement

Milk quality and adulteration checks cannot always be accurately represented by a single measurement or visual check. Heterogeneous physical and chemical parameters must be combined to evaluate quality profiles effectively.

Project Purpose

This project is an embedded multi-sensor system designed to check milk parameters in real-time. By monitoring acidity, temperature, density, suspended solids, and gas output, the kit provides an immediate classification of quality, serving as a low-cost, portable alternative to slow lab tests.

04 · Sensor Block Architecture

Physical System Flow

Milk Sample→ pH / Temp / TDS / Gas / Turbidity Sensors→ Arduino Processing Unit→ Decision Logic (Embedded C)→ LCD Output & LED Indicators
Sensors Implemented:
  • pH Sensor: Monitors acidity/alkalinity changes (sourness or chemical addition).
  • Temperature Sensor: Tracks storage context relevant to bacterial growth.
  • TDS Sensor: Measures total dissolved solids to identify milk density/water dilution.
  • Gas Sensor: Identifies ammonia/methane emissions indicating microbial souring.
  • Turbidity Sensor: Measures light transmission to observe optical density and solids.
05 · Key Features

Core Capabilities

Multi-Sensor Inputs

Monitors five separate chemical/physical dimensions simultaneously in one container.

Microcontroller Logic

Processes analog sensor signals, compiles averages, and applies filter logic to reject noise.

Status Classification

Compares sensor thresholds to classify samples into normal, stale, or adulterated grades.

Immediate Feedback

Displays raw sensor values on a 16x2 LCD, flashing distinct indicator LEDs for warnings.
